## 开发与验证原则

- V1 根目录业务文件禁止修改；新功能文件全部放在 /v2/。
- GitHub Pages 从 main 分支部署；Vercel 的自动部署在仓库根目录 vercel.json 中设为关闭。
- 禁止在前端硬编码 Lark Webhook/Token；GitHub Pages 仅生成**浏览器本地模拟通知**，不代表真实群聊通知送达。
- 原始订单 ID 为关联主键；服务资料及测试附件使用独立的本地存储键。后端接入前不跨浏览器同步。
- 修改累计三次并完成验证后再保存下一个 CP，回退时先备份当时的 V2 状态。
